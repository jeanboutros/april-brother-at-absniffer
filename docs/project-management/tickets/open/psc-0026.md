## Description
Implement the adapter layer that translates BLE-specific data to generic presence types. `BlePresenceAdapter` is the ONLY module that knows about both `ScanResultMessage` (BLE) and `PresenceSample` (generic). It reads from `DeviceRegistry` and produces `PresenceSample` for the `PresenceAnalyzer`.

This is a pure translation layer — no logic, no state, just type conversion. The adapter implements the Clean Architecture dependency rule: it sits in the adapter layer, translating between the device-specific outer layer and the generic inner layer.

**Key design decisions:**
1. BlePresenceAdapter is the ONLY module that includes both BLE headers and presence headers
2. `adapt()` maps: `ScanResultMessage.rssi` → `PresenceSample.signal_strength`, `ScanResultMessage.mac` → `DeviceId`, `Clock::now()` → `PresenceSample.timestamp`
3. `adapt_absent()` creates a `PresenceSample{.present=false}` for devices that haven't been seen recently
4. The adapter has no state — it reads from DeviceRegistry on each call and returns a new PresenceSample
5. This module MUST be the only bridge between BLE-specific types and generic presence types
