## Issue Description
`BluetoothATDriver` directly opens POSIX serial ports and has no abstraction for input/output. Three interfaces are needed:
1. `SerialPort` — enables mock-based testing of the driver
2. `PacketSource` — enables replay from files (psc-0019) and future input sources
3. `PacketSink` — enables JSONL output to stdout or files (psc-0017) and event output

## Change Suggested
- Create `SerialPort` abstract interface in `include/ble_sniffer/serial_hal.h`
- Create `PacketSource` abstract interface in `include/ble_sniffer/packet_source.h`
- Create `PacketSink` abstract interface in `include/ble_sniffer/packet_sink.h`
- Create `PosixSerialPort` implementing `SerialPort` using termios
- Make `BluetoothATDriver` accept `SerialPort&` (dependency injection) and implement `PacketSource`
- Create `MockSerialPort` for unit testing
- Refactor scan loop to use `PacketSource*` instead of direct `driver.read_line()`
